# PATFinder roadmap

Planned improvements, organized by priority. Scope and priorities may change.

## Now — Foundation

- [ ] **nf-core alignment:** refactor modules, scripts and configuration following nf-core conventions.
- [ ] **Reliable execution:** add automated tests and record software versions, database versions and parameters.
- [ ] **Flexible inputs:** support local genomes, MAGs and sample sheets.
- [ ] **Analysis and plots:** improve the analyses and visualizations generated by the pipeline.

## Next — Discovery

- [ ] **GECCO and DeepBGC:** integrate additional BGC detection tools.
- [ ] **Prediction integration:** consolidate overlapping regions and compare predictions across detectors.
- [ ] **Reference database:** reduce redundancy, review annotations and distinguish general biosynthetic hits from more specific antimicrobial-related evidence.
- [ ] **Candidate ranking:** combine evidence using transparent, configurable prioritization criteria.

## Later — Validation and reporting

- [ ] **Interactive report:** generate an HTML report with filters, BGC summaries and exportable results.
- [ ] **Detection benchmarks:** compare individual detectors and integrated predictions using reference datasets.
- [ ] **Ranking validation:** evaluate prioritization using BGCs with known biological activities.
- [ ] **Documentation:** provide tutorials, example datasets and guidance for interpreting results.

## Feedback and progress

Suggestions are welcome through [GitHub Issues](https://github.com/P3dror0cha/PATFinder-project/issues). Tracking issues can be linked to the items above as development progresses. Items will be checked off when released.
